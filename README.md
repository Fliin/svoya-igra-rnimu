# Своя игра · Корпорация Пирожкова

**[Открыть приложение](https://fliin.github.io/svoya-igra-rnimu/)** · [Репозиторий](https://github.com/Fliin/svoya-igra-rnimu)

Статическое приложение для командного вечера: HTML, CSS и JavaScript, без сервера приложения, учётных записей и сборки. Подготовлено для GitHub Pages.

## Запуск на компьютере

Нужен Node.js 22 или новее. В папке проекта выполните `npm start`, затем откройте [приложение](http://127.0.0.1:4173). Установка зависимостей не нужна. Для проверки игровой логики: `npm test`.

Папку `public` можно разместить на любом статическом хостинге. Открывать `index.html` двойным щелчком не следует: браузеры ограничивают загрузку JavaScript-модулей через `file://`.

## Как подготовить вечер

1. В «Банке вопросов» создайте темы и вопросы. Для вопроса и ответа можно добавить текст и одну ссылку на картинку или видео. Там же редактируются коты и модификаторы.
2. В «Настройке игры» задайте от 1 до 3 команд. Добавьте раунды, пять цен и до шести тем в каждый раунд. Кнопка клетки открывает редактор: вручную выберите вопрос из банка или создайте локальный вопрос только для этой клетки.
3. Отметьте нужные специальные клетки и выберите общие пулы котов и модификаторов. Снаружи клетки выглядят одинаково. Один вопрос нельзя назначить в разные клетки; темы могут повторяться между раундами.
4. Если нужен финал, включите его в настройках и назначьте ровно пять разных тем, по одному вопросу из банка в каждую. Тема может встречаться и в обычном раунде, но вопрос должен быть другим.
5. Исправьте ошибки проверки готовности. Репетиция доступна и для неполного поля или финала: отсутствующий вопрос получит поясняющую заглушку только в репетиции.
6. Запустите игру и при необходимости включите «На весь экран». Переключение обычных раундов свободное. Вопрос и ответ занимают отдельный экран с постоянным табло внизу.

Первое открытие загружает **демонстрационный набор**: 6 тем × 5 вопросов, 3 кота, 3 модификатора. Личные вопросы и фотографии в проект не включены.

## Как вести игру

В редакторе выберите «Картинка» или «Видео», вставьте ссылку и нажмите «Предпросмотр». Подходят прямые ссылки на файлы (например, PNG, JPG или MP4) и ссылки Google Диска с доступом для всех, у кого есть ссылка. Для внешних файлов используйте HTTPS. Игра сама открывает ссылки Диска через его встроенный просмотр. Кнопка «Открыть отдельно» ведёт на страницу файла.

Видео запускает ведущий кнопкой Play. Выбор команды или перехват сохраняет плеер открытым. При переходе к ответу или следующему вопросу старое видео останавливается. Перед мероприятием проверьте внешние файлы и звук на компьютере ведущего. Изменённый в банке вопрос нужно снова выбрать в клетке или в настройках финала, чтобы обновить его назначенную копию.

Откройте клетку. При специальном событии сначала появится его отдельный экран. Для кота назначьте стоимость и команду, которая отвечает первой. Кот заменяет обычный вопрос, а его текст выбирается из пула без повторений. Модификаторы выбираются случайно с возможностью повторения; кот и модификатор могут выпасть вместе.

Команды отвечают устно. Выберите отвечающую команду: над её табло появятся две кнопки с фактическими суммами. «Правильно» сразу начисляет баллы и показывает ответ; затем нажмите «Завершить вопрос». «Неправильно» сразу списывает баллы, оставляет ответ скрытым и запрещает этой команде повторную попытку. Выберите другую команду для перехвата. Каждая оценка учитывается один раз. Таймера нет.

Если все ошиблись или оставшиеся команды отказались отвечать, нажмите «Показать ответ», затем «Завершить вопрос». Новых начислений не будет, уже полученные штрафы сохранятся. После раскрытия ответа повторных кнопок «+» и «−» нет.

Множитель действует на начисление и списание. Фиксированное число **прибавляется** к операции при условии «начисление», «списание» или «каждая операция». Пример: при цене 300 фиксированный эффект +100 на списание даёт −200. Отрицательное значение усиливает штраф. Результат округляется до целого. Под каждой командой отображаются фактические суммы операций.

Нажатие на табло открывает ручную установку счёта без модификатора. Отрицательные очки разрешены. История сохраняет изменения счёта. После завершения вопроса клетка блокируется; ручная корректировка её не восстанавливает. Можно закрыть вопрос без ответа, сохранив текущий счёт.

Стрелка **Undo** в шапке отменяет последнее изменение: оценку и списание, выбор команды, открытие или закрытие клетки, изменения банка и настроек, импорт, сброс, действия финала. Отмена возвращает и данные, и соответствующий экран. Можно последовательно отменить до 50 действий; при больших играх число сокращается по лимиту памяти. История Undo действует только в текущей вкладке до обновления страницы и не переносится в JSON. `Ctrl+Z` вне полей ввода также вызывает Undo. Набранный, но ещё не сохранённый текст редактируется обычной отменой браузера.

## Финал и победители

Финал по умолчанию выключен, поэтому прежняя игра продолжает работать. Настройки финала фиксируются при настоящем старте. После обычных раундов нажмите «Перейти к финалу» и подтвердите переход. Вернуться к обычному полю можно через Undo перехода.

1. Ведущий нажимает на темы, которые команды решили исключить. Порядок команд приложение не навязывает. После четвёртого исключения остаётся одна тема.
2. Введите ставки до открытия вопроса: целые числа от 0 до текущего счёта. Участвуют все команды; при нулевом или отрицательном счёте доступна только ставка 0. Подтвердите ставки.
3. Команды отвечают устно по очереди в порядке табло. После каждого устного ответа ведущий нажимает «Ответ получен». Правильный ответ скрыт до получения ответов всех команд.
4. Покажите правильный ответ и по очереди оцените команды кнопками над табло. Верный ответ прибавляет ставку, неверный — вычитает. Модификаторы обычных раундов в финале не действуют.
5. Последняя оценка открывает пьедестал. Места определяются итоговым счётом; при равенстве команды делят место (например, 1, 1, 3). Без финала пьедестал открывается кнопкой «Завершить игру».

## Импорт вопросов из Excel

В «Банке вопросов» скачайте [шаблон Excel](public/templates/questions-template.xlsx), замените две примерные строки своими вопросами и нажмите «Импорт Excel». Одна строка — один вопрос. Первая строка содержит названия колонок:

| Тема | Вопрос | Ответ | Ссылка на картинку вопроса | Ссылка на картинку ответа | Ссылка на видео вопроса | Ссылка на видео ответа |
|---|---|---|---|---|---|---|
| Кино | Кто снял «Иронию судьбы»? | Эльдар Рязанов | | | | |

Первые три колонки обязательны. Колонки со ссылками можно оставить пустыми или убрать, поэтому старые шаблоны тоже подходят. Для каждой стороны укажите текст, картинку или видео. Если нужны текст и медиа, заполните текст и одну соответствующую ссылку. Читается лист «Вопросы», а если его нет, первый лист. Формат `.xlsx`, до 5 МБ и 10 000 строк. Старый `.xls` сохраните как `.xlsx`.

Предпросмотр показывает новые темы, вопросы, пропущенные повторы и ошибки с номерами строк. При ошибках ничего не добавляется. Темы с одинаковым названием объединяются без учёта регистра и лишних пробелов. Точные повторы текста, ответа и ссылок внутри темы пропускаются. Импорт добавляет данные только в банк. После импорта назначьте нужные вопросы клеткам и финалу в настройках.

Файл читается в браузере локальной копией SheetJS; загрузки таблицы на сервер нет. Шаблон скачивается с сайта и работает на другом компьютере.

## Резервная копия JSON и перенос на другое устройство

В главном меню и настройках есть «Экспорт JSON» и «Импорт JSON». Экспорт сохраняет всю настоящую игру: банк, котов, модификаторы, команды, раунды, назначенные вопросы, специальные пулы, счёт, историю, сыгранные клетки и текущий открытый вопрос. Финал переносится на любом этапе, включая исключения, ставки, очередь и уже оценённые ответы. Экспорт из репетиции недоступен.

Подготовьте игру дома, экспортируйте JSON, перенесите файл на другое устройство, откройте тот же сайт и импортируйте его. Предпросмотр покажет содержимое и прогресс. После подтверждения файл **целиком заменяет текущую игру и банк** в этом браузере. Восстановление можно отменить Undo в текущей вкладке. Повреждённый файл или неизвестная версия не меняет данные. Максимальный размер — 16 МБ.

JSON сохраняет ссылки и тип медиа для вопроса и ответа. Для показа картинок и воспроизведения видео нужен доступ к исходным файлам. Старые копии JSON с картинками поддерживаются.

## Сохранение и репетиция

Одна текущая игра автоматически сохраняется в `localStorage`: банк, назначенные копии вопросов, пулы, счёт, сыгранные клетки, активный вопрос, выбранный спецэффект и история. Для редакторов сохранение происходит по кнопке «Сохранить», для обычных настроек — при изменении поля. При возврате после обновления нажмите «Продолжить игру».

Репетиция создаёт отдельную временную копию с нулевым пробным прогрессом. Она не записывается в настоящее сохранение. Выход или обновление страницы отбрасывает пробные изменения. Настоящая игра остаётся на прежнем месте, включая незавершённый вопрос. При изменении игры в другой вкладке запись блокируется до обновления страницы, чтобы избежать потери прогресса.

Вопросы в клетках — копии банка. Редактирование банка не изменяет подготовленные клетки. После старта можно отдельно менять неоткрытые клетки; открытые и сыгранные защищены. Специальные пулы фиксируются при старте, поэтому редактирование банка не меняет уже начатую игру.

«Сбросить прогресс» после обычного окна подтверждения обнуляет счёт и сыгранные клетки, очищает ход финала, сохраняя поле, подготовку финала и банк. «Новая пустая игра» заменяет поле, сохраняя банк. Оба действия можно отменить Undo.

Данные привязаны к браузеру и адресу сайта. Для переноса между устройствами используйте JSON. Очистка данных сайта удалит сохранение. При недоступной прямой ссылке игра показывает ошибку загрузки. Шрифт загружается с Google Fonts, а без него используется системный. Исходники и демонстрационные вопросы публичного репозитория не содержат сохранений из браузера.

## Публикация на GitHub Pages

В проект включён `.github/workflows/pages.yml`: тестирование на Node.js 22, загрузка `public`, публикация в среду `github-pages`. Все ссылки относительные, поэтому приложение работает по адресу проекта `https://USER.github.io/REPO/`.

Если установлен и авторизован GitHub CLI (`gh auth login`), из папки проекта можно запустить:

```powershell
.\scripts\publish.ps1
```

Скрипт создаст новый публичный репозиторий `svoya-igra-rnimu`, включит Pages с источником GitHub Actions, отправит код, дождётся workflow и проверит HTTP-ответ опубликованного сайта. При конфликте существующего репозитория или отсутствии прав он остановится с ошибкой. Секреты в проект не записываются.

Можно опубликовать вручную: создать репозиторий, отправить проект в `main`, в **Settings → Pages → Source** выбрать **GitHub Actions** и запустить workflow. Проверить зелёный workflow и адрес из **Deployments → github-pages**. Наличие workflow-файла само по себе не подтверждает публикацию.
