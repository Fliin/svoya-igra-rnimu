# Проверка приложения

Дата: 19 ноября 2026 года. Платформа разработки: Windows, Node.js 24.20.0. Публикация настроена на Node.js 22 без внешних npm-зависимостей.

## Автоматические проверки

`npm test`: **20 тестов, 20 успешно**.

Проверены: готовность демонстрационного поля; запрет неполного старта; допустимость неполной репетиции; цены и команды; лимиты поля; отсутствие ответов; повторы между раундами; запрет баллов до ответа; повторные операции и отрицательный счёт; перехваты; совместные кот и модификатор; назначение команды и цены; розыгрыш без повторов; повторяемость модификаторов; недостаточные пулы; условия фиксированных эффектов; абсолютная корректировка; копии банка и фиксация пулов; защита открытых клеток; изоляция репетиции; сохранение активного события; ошибки и повреждение хранилища; закрытие без баллов; завершение и сброс; картинки без текста; запрет активных URL; отсутствие расхода кота при неудачном открытии.

Синтаксис всех модулей JavaScript проверен `node --check`. Синтаксис PowerShell-скрипта публикации проверен штатным парсером PowerShell. HTTP-проверка локального сервера: главная страница и модули возвращают 200. Исправлена нормализация пути сервера для Windows.

## Проверка в браузере

Через локальный сервер открыто и визуально проверено главное меню. Пройден игровой сценарий:

1. Репетиция демонстрационного поля с 30 клетками.
2. Открытие обычного вопроса; выбор первой команды; ошибка; перехват второй командой.
3. Раскрытие ответа. Первой команде −100, второй два начисления по +100. На табло получены −100 и +200.
4. Завершение вопроса и открытие клетки «кот + модификатор».
5. Отдельный экран события. Выпал бонус +100 за верный ответ. Введена цена 750 и назначена третья команда.
6. Вопрос кота: остальные команды заблокированы до первой ошибки. После раскрытия ответа третьей команде начислено 850.
7. Ручная корректировка счёта третьей команды до −50 без применения модификатора.

Дополнительно в браузере проверены:

- Создание, изменение и удаление темы и вопроса; отдельные банки котов и модификаторов; создание фиксированного эффекта −50 по условию «списание».
- Добавление второго раунда с повторной темой и ручное назначение свободного вопроса. Уже назначенные вопросы недоступны для повторного выбора.
- Режим одной команды, затем возврат к трём командам.
- Пустой ответ: появляется точная ошибка, кнопка настоящего старта заблокирована.
- Вопрос и ответ только с картинкой по абсолютному URL: файл загружается, изображение центрируется. Проверка сделана на URL локального сервера.
- Настоящий старт, раскрытие ответа, +100 первой команде, обновление страницы и продолжение: восстановились тот же открытый ответ и счёт +100.
- Подтверждение сброса: «Отмена» сохраняет начатую игру; «Сбросить» обнуляет счёт и прогресс, оставляя банк и поле.
- Репетиция неполного второго раунда: свободное переключение, открытие пустой клетки с поясняющей заглушкой, начисление +200, ручное завершение и экран результатов.
- Выход из репетиции отбрасывает пробный результат; настоящее поле остаётся в подготовке. Удаление тестового раунда подтверждается обычным диалогом.

Подтверждения реализованы обычным HTML-диалогом с кнопками, без кодового слова. После проверки исправлены сохранение черновых цены и команды кота, позиция прокрутки при переходе между экранами, компоновка вопросов только с картинкой и высота игрового поля. Все пять рядов цен видны над табло в проверенном окне браузера. Ошибок JavaScript в консоли при последнем прохождении нет.

Узкие экраны и реальный проектор отдельно не проверялись. Проверка изоляции репетиции и восстановления спецсобытия дополнительно включена в автоматические тесты.
