# Проверка приложения 1.1

Дата: 20 ноября 2026 года. Windows, Node.js 24.20.0. Публикация настроена на Node.js 22. Установка npm-зависимостей не требуется; SheetJS 0.20.3 включён локально с лицензией.

## Автоматические проверки

`npm test`: **60 тестов, 60 успешно**. Синтаксис всех модулей приложения, скриптов и тестов проверен `node --check`; `git diff --check` не выявил ошибок.

Проверены обычная игра и специальные клетки, немедленные начисления и штрафы, перехваты и запрет повторной оценки, отрицательные баллы, ручная корректировка, изоляция репетиции, сохранение спецсобытий без нового розыгрыша, готовность поля и финала.

Проверки переноса охватывают JSON с активным вопросом, котом и модификатором, неполными настройками и завершённой игрой; финал на каждом этапе; совместимость старого сохранения без финала; повреждённые структуры, ссылки, идентификаторы, ставки и очереди. Проверены фактический Excel-шаблон и локальная библиотека, слияние тем, повторы, картинки без текста, ошибки строк и отсутствие частичного импорта. Undo восстанавливает данные, право отвечать, клетку, импорт, сброс и последнюю финальную оценку.

## Проверено в браузере локально

- Обычный вопрос: выбор команды; неверная оценка немедленно даёт −100, команда больше не выбирается, ответ скрыт. Undo возвращает счёт и право отвечать. Верная оценка даёт +100 и раскрывает ответ; повторных кнопок начисления нет.
- Excel: скачиваемый шаблон с двумя вопросами даёт предпросмотр двух тем и двух вопросов. Импорт добавляет их в банк; Undo возвращает прежний банк.
- JSON: экспортирован настоящий файл резервной копии. Восстановление тестовой игры вернуло банк, штраф первой команды, активный вопрос и выбор второй команды. Undo полного восстановления вернул предыдущую завершённую игру с результатами.
- Настройки финала: пять слотов тем и вопросов; уже назначенные обычным клеткам вопросы недоступны. Неполный финал блокирует настоящий старт.
- Ведущий исключил четыре темы; Undo вернул исключённую тему. Осталась одна тема. Ставка выше счёта отклонена; отрицательный счёт разрешил только 0. Подтверждены ставки 300, 500 и 0; Undo подтверждения сохранил введённые значения.
- Ответ финала оставался скрытым до третьей команды. После раскрытия ведущий оценил ответы последовательно: −300, +500, 0. Итоговые счета 600, 1400 и −100, места 2, 1 и 3. Пьедестал показал правильный порядок. Undo последней оценки вернул финальный ответ, очередь и счёт; повторная оценка не удвоила предыдущие начисления.
- На последнем прохождении ошибок JavaScript в консоли нет. Пьедестал визуально проверен при 1280 × 720.

## Публикация

Адрес приложения: https://fliin.github.io/svoya-igra-rnimu/.

Репозиторий: [Fliin/svoya-igra-rnimu](https://github.com/Fliin/svoya-igra-rnimu), ветка `main`. Источник Pages — GitHub Actions, среда `github-pages`. [Результаты публикаций](https://github.com/Fliin/svoya-igra-rnimu/actions/workflows/pages.yml).

Workflow запускает тесты, загружает папку `public` и публикует её. Наличие файлов в репозитории само по себе не подтверждает развёртывание: для конкретного выпуска требуется статус `success` задания публикации. Результат этого развёртывания сообщается пользователю после завершения workflow.

Данные остаются в браузере посетителя. Локальный предпросмотр не переносится на GitHub Pages автоматически; теперь для этого предусмотрен JSON. В репозиторий включены исходники, Excel-шаблон и демонстрационный набор, без пользовательских сохранений и тестовых резервных копий.
