## Трактовки четырёх открытых нюансов

В исходной спецификации эти нюансы оставлены предложениями, а не отдельными согласованными решениями. В реализации приняты следующие значения по умолчанию:

1. Первоначальное ограничение MVP отменено: добавлены Excel для банка и полная резервная копия JSON с прогрессом.
2. Назначенная команда отвечает на кота первой; после её ошибки перехват доступен остальным.
3. Каждая оценка обычного вопроса учитывает модификатор. Абсолютная ручная корректировка его не учитывает.
4. Назначение вопроса создаёт копию в клетке. Редактирование банка её не меняет; неоткрытая клетка редактируется отдельно.

Первоначальная трактовка об отложенном списании отменена: теперь штраф применяется сразу при неверном ответе. Верная оценка сразу начисляет баллы и показывает ответ. Если все ошиблись, показ ответа и завершение не добавляют операций.

Пулы фиксируются при старте. Коты выбираются равновероятно без возвращения, модификаторы — равновероятно с возвращением. Обновление страницы сохраняет уже выпавшие события. При новой игре или сбросе прогресса пулы берутся из актуального банка заново.

Закрытые клетки не восстанавливаются ручной корректировкой. Undo закрытия возвращает открытый вопрос, Undo открытия — свободную клетку. Сброс всей игры является отдельным подтверждаемым действием и также отменяется через Undo.

## Импорт, резервная копия и Undo

- Excel `.xlsx`: только банк вопросов, одна строка на вопрос, колонки «Тема», «Вопрос», «Ответ» и две необязательные ссылки на картинки. Есть скачиваемый шаблон. Предпросмотр показывает ошибки строк и повторы; ошибочный импорт ничего не меняет. Импорт добавляет, не заменяет банк и не назначает вопросы полю.
- JSON: весь банк и вся настоящая игра, включая текущий прогресс, активное спецсобытие и финал. Предпросмотр и подтверждение полной замены. Перенос между браузерами и устройствами; картинки остаются внешними URL. Старые сохранения без финала совместимы.
- Undo: стрелка в шапке, до 50 последних изменений с ограничением памяти; отменяет банк, настройки, оценки, вопрос, импорт, сброс и финал целиком. Действует до обновления страницы в текущей вкладке; не входит в JSON. Репетиция не меняет настоящее сохранение.

## Согласованный финальный раунд

Финал включается отдельно. Заранее настраиваются ровно пять разных тем банка, в каждой вручную назначается один вопрос. Те же темы разрешены в обычных раундах, назначенные вопросы повторять нельзя.

Ведущий сам исключает четыре темы по устному решению команд. Приложение не задаёт очередь исключения. После выбора оставшейся темы все команды делают ставки до открытия вопроса. Ставки целые от 0 до текущего счёта; при счёте ≤ 0 доступна только ставка 0. Участвуют все команды.

Команды отвечают устно по очереди. Ведущий отмечает получение каждого ответа; правильный ответ можно открыть только после всех команд. Затем ведущий оценивает каждую команду: прибавляется или вычитается её ставка ровно один раз. Обычные модификаторы в финале не применяются. После последней оценки автоматически открывается пьедестал. Места определяются счётом, при равенстве делятся (1, 1, 3). Undo отменяет и последнюю оценку, и завершение игры.
